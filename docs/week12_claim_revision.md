## 结果段骨架（定稿用）
在本研究的 0.5B LoRA、固定数据混合及严格 token/update 协议下，所评估的 Safe 候选
未达到相对 Random 的登记非劣效标准（−3.589pp，example-level 95% CI [−5.231, −1.946]）。
门控日志显示：SafeGate 按设计工作——技能级过滤（激活中位 5/17）、22/245 轮回退恰好发生在
允许集合为空的轮次——但 Safe 显著差于其 LP-only+replay 父策略（−2.856pp）且与已冻结的
LP-Match-Replay 失败候选相当（+0.051pp）。这些结果限定了本实现的适用范围，
不足以推出能力感知课程在其他模型、任务和预算下普遍无效。

## 统计口径披露
- 主 CI：固定已训练 run 集合条件下、对测试题目重采样的配对区间（1319 题共享索引，B=10000）
- 重算与 Week 11 冻结 CI 端点存在 ~0.05pp 蒙特卡洛差异（实现层 RNG 流差异），点估计一致，两版均保留
- seed 敏感性（事后，rng 20250723）：−3.564pp CI [−6.065, −1.011]，并排报告、不替换原判据
- Random 既用于参考校准又用于比较，敏感性分析条件于已冻结 reference
